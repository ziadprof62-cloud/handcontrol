# تحكم بالإيماءات - تطبيق أندرويد (Kotlin)

يتحكم في **أي فيديو أو تطبيق** (يوتيوب، نتفلكس، VLC...) وفي **صوت التليفون**
بإيماءات اليد، حتى لو مفيش فيديو شغال.

| الإيماءة | الأمر |
|---|---|
| ✋ كف مفتوح | تشغيل |
| ✊ قبضة | إيقاف |
| 👍 إبهام لأعلى | رفع الصوت (يتكرر) |
| 👎 إبهام لأسفل | خفض الصوت (يتكرر) |

## التشغيل
1. ثبّت **Android Studio** (آخر إصدار) وافتح مجلد `HandControl`.
2. اترك Gradle يعمل Sync (وافق لو طلب تنزيل Gradle أو تحديث الإضافات).
3. وصّل تليفونك بكابل مع تفعيل **USB debugging**، واضغط Run.
4. أول مرة التطبيق بينزّل نموذج التعرف (حوالي 8 ميجا) تلقائياً، فلازم إنترنت.
   (اختياري: حمّل `gesture_recognizer.task` وحطه في `app/src/main/assets/`.)

## الاستخدام
1. افتح التطبيق، اضغط **ابدأ**، واسمح بالكاميرا.
2. افتح أي فيديو، ثم اضغط **Home** أو بدّل للتطبيق: هتظهر **نافذة صغيرة** عائمة
   فيها الكاميرا، والإيماءات تفضل شغالة فوق التطبيق.
3. زر **نافذة صغيرة** بيفتحها يدوياً.

## ملاحظات
- أوامر التشغيل/الإيقاف بتروح لآخر تطبيق شغّل صوت/فيديو. بعض التطبيقات القليلة
  ممكن تتجاهلها.
- الكاميرا بتقف لو قفلت النافذة الصغيرة أو التطبيق، أو لو الشاشة اتطفت.
- المشروع مكتوب بدون تجربة على جهاز فعلي؛ لو ظهر خطأ في البناء ابعته.
